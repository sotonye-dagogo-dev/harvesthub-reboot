# MyHarvestHub Beta Testing Checklist

Thank you for helping us test MyHarvestHub! Please work through each section below and report any issues you encounter.

---

## 1. ACCOUNT & AUTHENTICATION

### Create & Access Your Account

- [ ] Sign up as a new buyer (with email)
- [ ] Verify your email after signup
- [ ] Log in with your email and password
- [ ] Log out successfully
- [ ] Log back in to confirm session works
- [ ] Reset your password using "Forgot Password" link
- [ ] Update your profile information (name, phone, address)
- [ ] Upload a profile photo

### Sign Up as a Vendor

- [ ] Create a vendor account
- [ ] Complete vendor profile (store name, description, location)
- [ ] Upload store logo/banner
- [ ] Verify your email as a vendor
- [ ] Log in as a vendor account

---

## 2. BROWSING & DISCOVERY (As a Buyer)

### Browse Products

- [ ] View the home page and see featured products
- [ ] Search for a product by name
- [ ] Filter products by category
- [ ] Filter products by price range
- [ ] Sort products by popularity, newest, or price
- [ ] View product details page
- [ ] See product images and descriptions
- [ ] Check product availability (in stock/out of stock)
- [ ] View vendor information on product page
- [ ] Read customer reviews (if available)

### Browse Vendors & Promotions

- [ ] View vendor storefront
- [ ] See vendor's product listings
- [ ] Browse promoted banners on home page
- [ ] Click through banner promotions
- [ ] View special deals or flash sales

## 3. SHOPPING CART & CHECKOUT (Buyer)

### Add to Cart

- [ ] Add a product to cart from product page
- [ ] Add a product to cart from search/browse
- [ ] Add multiple different products to cart
- [ ] Add the same product with different quantities
- [ ] View cart with all items
- [ ] See cart item count in header
- [ ] Update item quantity in cart
- [ ] Remove item from cart
- [ ] Cart empties properly after checkout

### Checkout Process

- [ ] Start checkout from cart page
- [ ] Review order summary before payment
- [ ] See correct subtotal, taxes, and delivery fees

- [ ] Choose delivery method (if multiple options available)
- [ ] See all items and quantities before final submission
- [ ] Submit order successfully

## 4. PAYMENT METHODS (At Checkout)

### Wallet Payment

- [ ] View your wallet balance
- [ ] Add funds to wallet (if available)

- [ ] See wallet deducted after successful payment
- [ ] Order completes when wallet has sufficient funds

### Card/Online Payment

- [ ] Select card payment option at checkout

- [ ] See order confirmation after payment
- [ ] Receive order confirmation email

### Multiple Payment Methods

- [ ] Choose to split payment between wallet and card
- [ ] See correct amounts for each payment method
- [ ] Transaction completes successfully

---

## 5. VOUCHERS & DISCOUNT CODES (Buyer)

### Apply Valid Vouchers

- [ ] Apply an active voucher code at checkout
- [ ] See discount amount deducted from total
- [ ] Complete order with voucher applied
- [ ] Voucher is marked as used after purchase

### Invalid/Expired Vouchers

- [ ] Try to use an expired voucher (receives error message)
- [ ] Try to use a voucher with minimum purchase not met (receives error)
- [ ] Try to use a voucher on ineligible product category (receives error)
- [ ] Try to reuse a voucher that's already been used (receives error)
- [ ] Remove voucher code and checkout without it

### Voucher Limits

- [ ] Try to use same voucher twice in one order (rejected if not allowed)
- [ ] Receive clear error message for invalid vouchers

## 13. SECURITY & RESTRICTION TESTS

### Try to Bypass Restrictions

- [ ] Try to access vendor dashboard as buyer (should be blocked)
- [ ] Try to access buyer checkout as vendor (should redirect)
- [ ] Try to edit another vendor's product (should be blocked)
- [ ] Try to access admin area as regular user (should be blocked)
- [ ] Try to place negative quantity in cart (should reject)
- [ ] Try to checkout with empty cart (should prevent)

### Payment Security

- [ ] Try to checkout with insufficient wallet/card funds (rejected)
- [ ] Try to manually change order price in browser (should not affect actual charge)
- [ ] Try to submit order twice rapidly (should prevent duplicate)
- [ ] Session ends after logout and requires login again

### Voucher Restrictions

- [ ] Try to apply voucher to ineligible product (rejected)
- [ ] Try to use expired voucher (rejected)
- [ ] Try to use voucher past usage limit (rejected)
- [ ] Try to combine vouchers (allowed/rejected based on policy)

## GENERAL NOTES

**Please report any issues you find, including:**

- Feature not working as expected
- Confusing error messages
- Slow loading times
- Incorrect calculations (prices, discounts, etc.)
- Buttons that don't work
- Page crashes or freezing
- Typos or confusing wording
- Payment failures or wallet issues
- Any security concerns

**For each issue, please note:**

- What you were trying to do
- What happened (or didn't happen)
- What you expected to happen
- Your account type (buyer/vendor/guest)
- Browser and device used
- Any error messages you saw
